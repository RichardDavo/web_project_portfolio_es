# Proyecto portafolio

Este proyecto nació como parte de mi proceso de aprendizaje en desarrollo web. El objetivo fue poner en práctica mis conocimientos de HTML y CSS, creando una página personal donde pudiera presentar mi perfil, mis habilidades y algunos de los proyectos que he desarrollado.

El desarrollo de este portafolio fue un reto muy interesante, especialmente porque todavía estoy dando mis primeros pasos en el mundo del desarrollo web.

Aunque tiene un nivel de dificultad medio para alguien que está comenzando, me permitió enfrentar situaciones reales de maquetación, organización del código y adaptación de diseños a diferentes tamaños de pantalla.

Uno de los aspectos que más me interesó fue convertir un diseño de Figma en una página web funcional, intentando respetar lo máximo posible las dimensiones, los espacios, las tipografías y la distribución de los elementos.
